# TicketNXT

بوت تذاكر (Tickets) لسيرفرات Discord.

## الشفافية

هذا المستودع عام حتى يتمكن مالكو السيرفرات والمستخدمون من **الاطلاع على الشيفرة المصدرية ومراجعتها** لفهم طريقة عمل TicketNXT والصلاحيات التي يطلبها.

إتاحة الشيفرة للاطلاع لا تعني أن المشروع خضع لتدقيق أمني مستقل، ولا تُعد ضمانًا مطلقًا بخلوّه من الأخطاء أو الثغرات. ننصح بمراجعة الشيفرة والصلاحيات المطلوبة قبل إضافة البوت إلى أي سيرفر.

## الأمان والخصوصية

- راجع صلاحيات البوت المطلوبة في Discord قبل دعوته.
- لا تشارك رموز البوت (Bot Tokens) أو أسرار OAuth أو ملفات البيئة.
- لا ترفع كلمات المرور أو مفاتيح API أو بيانات الجلسات إلى GitHub.
- راجع [سياسة الإبلاغ عن الثغرات](SECURITY.md) إذا اكتشفت مشكلة أمنية.

## حقوق الاستخدام

الشيفرة متاحة للعامة **للاطلاع والمراجعة فقط**. جميع الحقوق محفوظة لصاحب حقوق النشر، ولا يُمنح بموجب هذا المستودع ترخيص عام لنسخ الشيفرة أو تعديلها أو إعادة توزيعها أو استخدامها في مشروع آخر، باستثناء الحقوق التي تفرضها شروط GitHub أو القوانين المعمول بها.
